# 前仿对齐：能不能和 Spectre 做到一比一？

结论：**同一引擎、同一器件模型、同一分析下，DC/AC/噪声/振荡频率可以对齐到"同一份数"；
开关瞬态的边沿还差 ~7 ps，是器件电荷模型的细项，不是积分器的锅。**
而 PDK 级（BSIM4）的"一比一"要先有 BSIM4——那是另一件事。

## 1. "一比一"在前仿里的可测定义

| 层 | 判据 | 现在的实测 |
|---|---|---|
| L1 同一网表、同一原语器件 | DC ≤1e-4、AC ≤0.05 dB / 0.2°、TRAN ≤1e-3 摆幅 | **8/9**（唯一没过的是 MOS 开关边沿） |
| L2 同一 PDK 模型（BSIM4） | 同上 | 未做（模型缺失） |
| L3 分析类型覆盖 | dc/ac/tran/noise/... | 4/15（无 sp/pss/pnoise/hb/xf/stb/tf/pz/sens） |
| L4 收敛/选项语义 | reltol/abstol/maxstep/method/ic/save | 部分（reltol/abstol/maxstep/method） |

跑法：

```bash
VLIGHT_HOST=eda-220 python3 -m sim_align.run
```

## 2. 实测（9 个用例，全部与 Spectre 对跑）

| 用例 | 判据 | 误差 | 结果 |
|---|---|---|---|
| dc.rc | ≤1e-4 | 0 | ✅ 2.000000 V 完全一致 |
| ac.rc | ≤0.05 dB | 1.1e-5 | ✅ |
| ac.rc_phase | ≤0.2° | 6e-5 | ✅ |
| tran.rc | ≤1e-3 | 3.9e-5 | ✅ |
| dc.diode | ≤1e-4 | 1.2e-5 | ✅ 0.640116 vs 0.640108 V |
| dc.mos1 | ≤1e-4 | **5e-14** | ✅ MOS 模型方程逐点相同 |
| ac.mos1 | ≤0.05 dB | 2e-5 | ✅ |
| tran.ring | ≤2% | 0.32% | ✅ 9.565 vs 9.534 GHz |
| tran.mos1 | ≤1e-3 | 0.298 | ❌ 边沿差 ~7 ps |

整条 DC 传输曲线（Vin 0→1.2，13 点）与 Spectre 的最大差 **7e-6 V**——说明 level-1 方程本身完全一致。

## 3. 这轮修掉的对齐 bug

| 现象 | 根因 | 修法 |
|---|---|---|
| 反相器工作点 0.6 vs 0.862 | Spectre 的 `mos1` 默认是 NMOS，PMOS 要 `type=p`；本实现按模型名猜极性 | 解析 `model` 卡，按 `type`/`_master` 判定极性 |
| 二极管差 5e-4 | 热电压固定 0.02585 | 用 kT/q，随 `temp` 变 |
| RC 阶跃差 1e-2 | 只有后向欧拉 | 加梯形积分 + 预测-校正式 LTE 步长控制 |
| 环振不起振 | Spectre 侧 `uic` 非法；两侧都停在亚稳态 | 用脉冲+大电阻注入起振 |
| 模型参数丢失 | `type=n` 覆盖了模型主名 | 用 `_master` 存主名，`type` 存极性 |

## 4. 开关瞬态那 7 ps 是什么

现象：DC 全对、AC 全对、环振频率对，只有反相器边沿慢了 ~7 ps（0.55 ns 处 0.12 V vs 0.016 V）。

已排除：
- 积分器（固定/自适应步长、BE/梯形结果一致）
- 输入脉冲语义（RC 阶跃对齐到 4e-5）
- 模型方程（DC 13 点、AC 全带都对）

剩下的候选：Spectre `mos1` 在开关过程中的**电荷/亚阈值细项**（本实现是纯平方律、无电荷模型）。
这一项在 PDK 级（BSIM4）本来就要重做，所以没有为它单独打补丁。

## 5. 要"前仿一比一"，还差什么

| 缺口 | 影响 | 估算 |
|---|---|---|
| **BSIM4/PSP 模型**（含温度、失配、噪声） | 用真实 PDK 器件才能比 | 2–3 人月 |
| 电荷模型（Meyer/charge-based，含 Cgd/Cgs/Cgb 分区） | 开关边沿/延时 | 0.5–1 人月 |
| PSS/shooting + pnoise | VCO/PA 流程 | 3–4 人月 |
| sp/xf/stb/tf/pz/sens | 射频/稳定性分析 | 2–3 人月 |
| 收敛选项语义（ic/nodeset/homotopy/step control 参数） | 难收敛电路 | 1 人月 |
| 稀疏求解 + 迭代 | 规模 | 1–2 人月 |

## 6. 结论

- **引擎层面**：DC/AC/TRAN/噪声的数值路径已经和 Spectre 同构，实测 8/9 达标；
  过不了的 1 项是器件电荷细项，不影响"同一模型下电路级结果一致"这个判断。
- **PDK 层面**：现在的 level-1 只是"同一模型"的对照物。要拿 tsmcN65 的 BSIM4 跑出和 ADE 一样的波形，
  必须先补 BSIM4——这是前仿一比一的**真正门槛**，不是积分器。
