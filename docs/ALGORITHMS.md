# 全流程算法图（每个阶段用什么算法、在哪、怎么验）

目标：**每一步都能脱离 Cadence 跑通并验证**。下面按设计流程排列，标出算法、实现文件、
复杂度、以及本仓库里对应的验证（都是可复现的实验，不是"应该能行"）。

```
规格 → 电路 → 网表 → 仿真 → 测量 → 版图(PCell/布局/布线) → 验证(DRC/LVS) → 寄生提取 → 后仿 → 优化/良率
        ↑                                              ↓
        └──────────── 自研 SPICE 引擎（MNA/Newton）──────┘
```

## 1. 仿真：自研 SPICE（`spice.py`）

| 环节 | 算法 | 复杂度 | 验证 |
|---|---|---|---|
| 方程建立 | 改进节点分析 MNA：未知量 = 节点电压 + 电压源/电感支路电流 | O(N²) 存储（稠密） | RC 分压 2.000 V |
| 非线性求解 | Newton-Raphson + 伴随模型（`A=J, b=J·v0−I(v0)`） | O(N³)/迭代 | CMOS 反相器开关点 0.6 V |
| 收敛 | gmin stepping（1e-3→0，逐级用上一解热启动）+ 源步进 + pn 结限幅 | 最多 200 次迭代 | 二极管 Vd 与二分法解一致到 1e-5 |
| DC | 上述牛顿的稳态解 | — | RLC、镜像、反相器 |
| AC | 复 MNA：C→jωC、L→jωL，工作点处线性化 gm/gds/gmb | 每频点 O(N³) | RC 幅相与解析解差 <1e-6 |
| 瞬态 | 后向欧拉伴随模型（C: Geq=C/h，L: 支路方程），步长自适应 | O(N³)/步 | RC 阶跃误差 9e-4 |
| 噪声 | 伴随法：解 Aᴴy=e_out，各源 PSD 加权求和 | 每频点 1 次分解 | RC 积分噪声 = kT/C，误差 0.05% |
| 器件 | R/C/L/V/I/E(VCVS)/G(VCCS)/D(肖克利)/M(level-1，含体效应) | — | 见上 |

关键坑（都踩过并修了）：支路下标差 1、gmin 停在中间解、电容伴随电流符号、
MOS 用对称电导代替非对称雅可比、`num()` 丢负号、AC 源缺省 mag=1。

与 Spectre 交叉验证：同一 RC 网络、同样的 `ac` 分析，幅频最大相对误差 <2%、相位 <0.02 rad。

## 2. 网表（`netlist.py` / `spicein.py` / `cdf.py`）

| 环节 | 算法 | 说明 |
|---|---|---|
| 层次展开 | 后序拓扑 + 参数绑定替换 | subckt 实例化、`{}`/同名替换 |
| 参数求值 | CDF 有效值 = 实例覆盖 > 基准默认；`iPar/pPar` 解析 | 见 `cdf.py` |
| 网表生成 | 器件映射表 + `netlistProcedure` 分派 | PDK 签名对照 |
| 网表反读 | 行级状态机（续行/注释/subckt/analysis/params） | 真实 VCO/OTA 往返一致 |

## 3. 测量（`measure.py`）

| 指标 | 算法 | 验证 |
|---|---|---|
| 频谱 | FFT + Hann/Blackman 窗 + 峰值插值 | 1 MHz + 0.01 三次谐波 → THD = −40.00 dB |
| THD/SNDR/SFDR | 谐波 bin 求和 / 噪底积分 | SFDR = 40.0 dB |
| 带宽 | 对数幅频插值找 −3 dB | RC 159.16 MHz，误差 0.25% |
| 相位/增益裕度 | 环路增益相位展开 + 0 dB/−180° 交点插值 | 双极点系统 PM = 9.4° |
| 建立/上升/过冲 | 包络带判定 + 线性插值穿越 | RC：tr = 2.2τ，ts(1%) = 4.6τ |
| 频率/抖动 | 过零点序列统计 | 环振 9.7 GHz |
| 眼图 | 按 UI 折叠 + 分位点 | — |

## 4. 版图几何（`pcell.py` / `polybool.py` / `gdsio.py`）

| 环节 | 算法 | 复杂度 |
|---|---|---|
| 参数化单元 | 参数→中线→线宽扫掠（矩形/角块）+ via 阵列 | O(段数) |
| 电感 | 八边形螺旋中线 + 修正 Wheeler 公式 | O(n) |
| 多边形布尔 | 扫描线 + 梯形分解：区间求并/求交 | O(V·E) |
| 面积/重叠 | 同上，逐带累加 | O(V·E) |
| GDS 读写 | 记录流 + excess-64 浮点 + SREF 层次 | O(图形数) |

验证：10×10 方块并/交 = 150/100；三角面积 50；KLayout 读回 58 图形、层号取自 layermap。

## 5. 布局与布线（`place.py` / `route.py`）

| 环节 | 算法 | 验证 |
|---|---|---|
| 布局 | Fruchterman-Reingold 力导向（弹簧+斥力+退火步长） | 8 单元 HPWL 806→311（−61%） |
| 合法化 | 行槽贪心最近位 | 重叠 0 |
| 布线 | A* 迷宫（曼哈顿启发 + 拐弯惩罚 + 过孔代价） | 绕障碍 75 格；两层必须打孔 |

## 6. 物理验证（`drc.py` / `connect.py` / `lvs.py`）

| 环节 | 算法 | 验证 |
|---|---|---|
| DRC | 边对距离（最小宽度/间距）、面积、网格、via enclosure | 三条违规全中 |
| 连接性提取 | 并查集：同层接触 + via 栈跨层 + label 命名 | 3 节点、短路告警 |
| LVS | 图同构：WL 颜色细化 + 端口锚定 + 回溯（带器件多重集剪枝） | 全改名电路 → MATCH；拆一根线 → MISMATCH |

## 7. 寄生提取（`extract.py`）

| 量 | 模型 | 验证 |
|---|---|---|
| 电阻 | 方块电阻 × L/W（长边定向） | 100×1 µm、0.1 Ω/sq → 10.000 Ω |
| 对地电容 | Ca·A + Cp·P | 19.16 fF |
| 耦合电容 | ε0·εr·A_overlap/d | 层间重叠取样 |
| 场求解（可选） | 2D 有限差分 Laplace + 能量积分 | 1×1 µm、εr=4 → 4.1e-10 F/m |

## 8. 优化与良率（`opt.py`）

| 环节 | 算法 | 验证 |
|---|---|---|
| 尺寸优化 | Nelder-Mead 单纯形 + 坐标下降备选 | 二次型收敛到解析最优 |
| 蒙特卡洛 | 独立/相关正态抽样（Cholesky） | 1/R 均值 1.0006（解析 1.000625） |
| 良率 | 上下规格命中率 + Cpk | 5% 电阻偏差 → 良率 ~95% |

## 9. 端到端闭环（可跑的三条链）

1. **前仿**：SKILL 建图 → 网表 → 自研 SPICE（或 Spectre）→ 测量/OCEAN
   - 分压器 1k/2k：DC 2.000 V；扫 R2：1.5/2.0/2.25 V
2. **后仿**：版图 → 提取 RC → 自研 SPICE → 与原理图对比
   - 100 µm 走线：R=10 Ω、C=19 fF，RC 时间常数与解析一致
3. **验证**：版图 → 连接性提取 → LVS 图同构 → DRC
   - 真实工程 LNA 与 PDK 模型：Spectre 0 error；网表与 SKILL 导出逐行一致
